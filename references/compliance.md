# 合规红线与措辞规范

本项目面向大众传播（结业证会被发到朋友圈），措辞必须经得起审核。

## 一、禁止的评价性表述

不要对麦当劳产品做价值判断。**只讲营养学事实，不做道德评价。**

| 禁止 | 原因 | 改成 |
|---|---|---|
| 垃圾食品、不健康、罪恶、发胖 | 贬损产品，违反活动规则中"不得贬低麦当劳品牌、产品及形象" | 这份餐品的钠占全天参考量的 64% |
| 必须戒、不能吃、别再点了 | 价值判断 + 制造焦虑 | 这一餐的钠偏高，下一餐可以选钠低一些的 |
| 热量炸弹、罪恶的一餐 | 道德说教 | 这一餐 726 kcal，约占成人全天能量参考量的 32% |
| 超标了、有问题 | 无参照系的恐吓 | 达到全天参考量的 80% |
| 减肥失败、胖了 | 医疗/健康断言 | 不做任何与体重变化的断言 |

## 二、百分比口径

**所有百分比一律以全天参考摄入量为分母。**

不要用"一餐参考量"当分母。反例：一餐参考量 = 全天 ÷ 3，于是巨无霸的钠（961 mg）
除以 500 mg 会得到「192%」——这个数字会被读成"超标将近两倍"，是夸张且误导的。

正例：961 mg ÷ 1500 mg（成人全天钠参考量）= 全天的 64%。

代码里两个口径都算好了，用 `pct_of_day`：
- `pct_of_day` — 占全天参考量，用于对外展示
- `pct_of_meal` — 占一餐参考量，仅用于内部判断"这餐某项是否值得讲"

## 三、必须标注的声明

课程页与结业证底部都要有：

- 营养素参考摄入量采用《中国居民膳食营养素参考摄入量》成人 18-49 岁轻体力活动水平
- 仅供营养科普参考，**不构成医疗、营养或其他专业建议**
- 餐品信息、价格及供应状态以麦当劳官方渠道的实时结果为准

## 四、数据呈现规范

- 能量等数字标注为**估算参考值**（不同批次、产地、季节、餐厅烹制会有差异）
- 演示数据必须明确标注是"演示数据"及其来源与更新时间，不能让人误以为是实时数据
- 不用极端值做标题党（"比你想的还高"这类）

## 五、行为红线

- **不创建订单、不取消订单、不消耗积分、不抽奖、不领券。** 只读 Tool 就够了。
- 不索取、不存储用户的麦当劳账号密码或 Token；`mcp-config.example.json` 只用 `${MDN_MCP_KEY}` 占位符
- 不做与医疗、疾病、减肥承诺相关的建议；涉及疾病与特殊膳食人群一律提示咨询专业营养师或医生
- 不对儿童做个体化的膳食处方（课程是通用科普）

## 六、活动规则要点速查（来自 activityGuidelines.md）

提交项目时尤其注意：

- 仓库需**公开可访问**
- 需包含 README.md / CONTEST_DECLARATION.md / MCP_INTEGRATION.md / mcp-config.example.json / workbuddy.md 五个文件，**文件名不可改动**
- 参赛项目须**真实使用麦当劳 MCP 能力**
- 内容不得含政治敏感内容、赌博、迷信、暴力、歧视、恶意脚本、钓鱼链接、指向违规站点的外链
- 不得"宣扬不健康饮食方式、奢靡浪费、拜金主义、娱乐至上等错误观念"——这也是本项目坚持"只讲数据不做说教"的原因
- 排名按 GitHub 公开 Star 数，Star 数为 0 的项目不进入排行榜
- 同一 GitHub 账号有多个参赛项目的，仅 Star 数最高的进入排行榜
